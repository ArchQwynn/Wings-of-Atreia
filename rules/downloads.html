Official Wings of Atreia Character Sheet

The official Character Sheet is a three-page player aid. The sheet records the character; it does not create new rules. If a field summary and the governing rules differ, use the current Player Handbook and Core Rulebook.

For a public website download, a PDF or fillable PDF is preferable to a Microsoft Publisher source file because players can open it directly in ordinary browsers and PDF applications.

What the Three Pages Contain

Page 1

Character, Core Statistics & Flight

Use this page for your core identity, defensive/offensive values, HP, and the Daeva flight information needed during play.

Page 2

Skills, Features & Adventure Tracker

Use this page for Skill Proficiencies, class/universal features, and the ongoing trackers associated with your character's adventures.

Page 3

Equipment, Inventory, Resources & Actions

Use this page for equipment and carried items, class resources, and frequently used attacks, spells, abilities, and action references.

Timing and Resource/Cost Fields

For each frequently used attack, class feature, spell, or ability, record its Timing as Action, Bonus Action, Reaction, Triggered / No Action, Passive, On Hit, or As Spell, together with Attack/DC, Damage/Effect, Range, Resource/Cost, and Notes.

The current native character-sheet artwork may still label two of these columns “Use” and “Cost.” For the current rules reference, read them as “Timing” and “Resource/Cost.”

Character Sheet Maintenance

  • On level-up, update Maximum HP, Proficiency Bonus, passive values, Flight Slots, Exploration Flight, Inventory Slots, class-resource caps, and all other level-dependent values.
  • During play, keep Current HP, Temporary HP, Flight Slots, class resources, ammunition, consumables, Death Saves, Exhaustion, and Reaction availability current as they change.
  • If you are unsure how a value is calculated, use the governing rule first, then record the resulting value on the sheet.
