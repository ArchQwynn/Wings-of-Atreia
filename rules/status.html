Rules Authority at a Glance

  1. Later explicit WoA approval wins over older drafts or superseded wording.
  2. Core Rulebook controls universal mechanics.
  3. Player Handbook controls player-facing creation, class progression, and detailed spell text.
  4. Game Master’s Guide controls GM world truth, geography, campaign procedure, and protected setting material.
  5. FAQ explains and cross-references approved rules; it does not replace the governing publications.
  6. Website is the fast player reference. If a summary ever conflicts with the current approved books, use the current approved book rule.

Update Workflow

When rules or mechanics change, Wings of Atreia first synchronizes the Player Handbook, Core Rulebook, Game Master’s Guide, and FAQ. Other affected books are updated as applicable, followed by the website, and then the Character Manager wherever character data or behavior is affected.
