Current Website Authority

If a downstream book or the Character Manager conflicts with a current website mechanic, the website mechanic is authoritative and the downstream artifact must be corrected.

Synchronization rule. A mechanics change begins with the GitHub website. After the website is updated, review every affected book and the Character Manager and synchronize them to the new website rule. Non-mechanical website changes do not automatically require downstream updates.

Rules Authority at a Glance

  1. GitHub Website — authoritative source for current Wings of Atreia mechanics.
  2. Books — explain and publish the mechanics established by the website.
  3. Character Manager — implements the mechanics established by the website.
  4. GM-only material may remain outside the public website; this hierarchy concerns mechanics, not the requirement to publish every piece of campaign or lore content online.

Update Workflow

  1. Update and verify the mechanic on the GitHub website.
  2. Record the website Rules Reference version when the change warrants a version increment.
  3. Review affected books and update their mechanics and cross-references.
  4. Review the Character Manager and update any affected character data, calculations, validation, or automation.
  5. Record the website Rules Reference version against the synchronized downstream releases.
