Website Changelog

A concise record of player-facing website improvements, clarifications, and reference-tool updates. Rules authority still follows the current approved publications shown on the Rules & Publication Status page.

This changelog describes the website reference experience. A website usability change does not itself create or alter a game rule.
14 September 2026

Player Reference Upgrade

AddedAt-table Reference Tools

Favorites, Recently Viewed pages, and a global Quick Reference drawer are now available throughout the site and are stored locally on the player’s device.

AddedMobile & Sharing Tools

Improved mobile navigation, page sharing, direct section-link copying, reading progress, and a Back-to-Top control were added for long reference pages.

AddedOffline Awareness

The header now shows a compact rules/offline status badge. The site can alert players when a newer offline reference has been downloaded and is ready to reload.

ImprovedAccessibility

Keyboard skip navigation, stronger visible focus treatment, larger touch targets, reduced-motion support, and higher-contrast preferences were added.

AddedInstallable Full Offline Reference

The player-facing site can be installed as a PWA and prepares the complete listed reference bundle for offline use, with a visible Ready status when caching completes.

ImprovedSearch

Search is site-wide, category-aware, supports partial matching, highlights matching text, and includes keyboard result navigation.

AddedRules Compendium & Expanded Glossary

Fast rule lookup, A–Z glossary navigation, and cross-links were added for in-session reference.

ImprovedSpell & Class Browsing

The spell library gained multi-filter browsing and full effect-text search. Class pages gained sticky on-page navigation and direct spell-list links where applicable.

AddedNew Player, Faction & World Navigation

A guided Start Here journey, expanded faction guidance, interactive Gazetteer, expanded region entries, campaign-start context, and player-safe Lord references were added.

AddedPublication Status

A dedicated Rules & Publication Status page now identifies the current reference baseline and the standing synchronization workflow.
