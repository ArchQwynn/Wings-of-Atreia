HTML Entry Checklist

  • Keep level IDs in the format level-1 through level-20.
  • Use the existing class-page CSS classes: mechanic-box, ultimate-box, subfeature, specialization-card, rule-table-wrap, and rule-table.
  • For tables, include a thead with column headings and place data rows inside tbody.
  • For glossary entries, keep terms alphabetical and definitions concise; the glossary must not create new rules.
  • For collapsible level entries, use details with a summary heading. Do not remove the level's ID.
  • Escape literal angle brackets in displayed HTML snippets as &lt; and &gt; if you write code examples directly into the page source.
  • After editing, check the page on desktop and mobile and verify that every quick-navigation link still works.
