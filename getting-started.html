Wings of Atreia

Character Manager — Getting Started

A step-by-step guide for Game Masters and players. No screenshots are required: follow the labels and controls shown in the Character Manager.

Quick Start For Game Masters For Players Returning Players Troubleshooting Character Companion

Quick Start

Important: a new player does not create a normal public account. The Game Master creates a private Player Access Code first.

Correct order

GM signs in with the GM access code
GM opens GM Player Access
GM uses Generate Player Code
GM privately gives the code to the player
Player enters the code on the Character Manager login screen
Player chooses New Character
The new character is saved under that player's access

For Game Masters

1. Sign in as the GM

  1. Open the Wings of Atreia Character Manager.
  2. On the opening screen, find the field asking for a Wings of Atreia access code.
  3. Enter your current GM access code.
  4. Use the sign-in/continue control directly below the access-code field.
  5. After GM access is accepted, the GM controls will become available.
Keep the GM access code private. Do not give the GM code to players.

2. Create access for a new player

  1. In the GM controls, locate GM Player Access.
  2. Open that section.
  3. Use Generate Player Code.
  4. The Character Manager will create a private player code in the format used by the app.
  5. Copy that player's code carefully.
  6. Send the code privately to the correct player.
Give each player their own Player Access Code. Do not reuse one player's code for another player.

3. Tell the player how to enter

Give the player only these two things:

  • the normal Character Manager link; and
  • their private Player Access Code.

Tell the player to open the Character Manager, enter their code in the Wings of Atreia access code field, then continue.

If this is their first time using that code, they can choose New Character and create their character.

4. Existing characters and assignments

GM Player Access can also be used when the GM needs to manage which existing characters are available to a player.

Before creating a replacement character because something appears missing, verify the player's access assignment first.

5. Multiple characters

A player may own multiple Wings of Atreia characters, but only one character is played by that player in a session.

When a player creates another character while signed in under their own Player Access Code, the newly created character is automatically associated with that player access.

For Players

1. Get your Player Access Code

Before you create a character, your Game Master must give you a private Player Access Code.

You should receive:

  • the Character Manager link; and
  • your personal Player Access Code.
If you have not received a Player Access Code, contact your GM before trying to create a character.

2. Sign in

  1. Open the Character Manager link from your GM.
  2. Find the field labeled for the Wings of Atreia access code.
  3. Enter your Player Access Code exactly as your GM provided it.
  4. Use the sign-in/continue control directly below the field.
  5. When the code is accepted, your player area will open.

3. Create your first character

  1. If you have no character yet, choose New Character.
  2. Complete each part of character creation shown by the Character Manager.
  3. Choose your faction: Elyos or Asmodian.
  4. Choose one of the available classes.
  5. Complete the remaining required character details and choices.
  6. Review the character before saving.
  7. Save the character and wait for the Character Manager to confirm the save.

The Character Manager is the official player character record and management tool. Current Wings of Atreia rules remain authoritative if a display summary ever conflicts with the books.

4. Keep your access code private

Your Player Access Code is used to reach your characters.

  • Do not post it publicly.
  • Do not give it to another player.
  • Do not use another player's code.
  • If you think someone else obtained it, contact your GM.

Returning Players

  1. Open the Character Manager.
  2. Enter the same Player Access Code issued by your GM.
  3. Continue past the access screen.
  4. Your authorized character list will appear.
  5. Select the character you want to use.
  6. Open/load the character.
  7. Use the Character Manager normally during play.
If a character you already created is missing, do not immediately make a duplicate. Contact your GM so the player access assignment can be checked first.

During play

Keep live character information current, including where applicable:

  • Current and Temporary HP
  • Flight Slots
  • class resources
  • Daeva Points
  • equipment and inventory changes
  • consumables and ammunition
  • conditions and other live-play state
  • spell, feature, Specialization, and Profession information

Troubleshooting

My Player Access Code does not work

  1. Check that you entered the code exactly as provided.
  2. Remove accidental spaces before or after the code.
  3. Make sure you are using the current Character Manager link.
  4. If it still fails, contact your GM.

I signed in, but I see no characters

If this is your first time, choose New Character.

If you previously had a character, contact your GM before creating another one.

The Character Manager looks outdated

Refresh the page first.

On Windows, use Ctrl + F5 for a full browser refresh if the older interface is still being shown.

The app says offline data is not ready

Open the Character Manager while connected to the internet and allow the required application files to finish loading. Once the app reports that its offline data is ready, cached parts of the Character Manager can be used according to the app's offline capabilities.

I lost my Player Access Code

Contact your Game Master.

Do not create a second player identity simply because you cannot find the original code. The GM should check your existing player access first.

GM: a player cannot see an existing character

Open GM Player Access and verify the player's character assignment before creating or authorizing a replacement.

Remember:
GM creates the Player Access Code first.
Player signs in with that code.
Player then creates or opens their authorized character.
