# Wings of Atreia — Website Rules Reference v1.0.0

**Effective:** 28 September 2026

## Authority Model

The **GitHub website is the overall authoritative mechanical reference for Wings of Atreia**.

All other player-facing and rules-supporting artifacts follow the mechanics established on the website:

1. **GitHub Website — authoritative rules reference**
2. **Books — publications that explain and present the website mechanics**
3. **Character Manager — application implementation of the website mechanics**

If a book or the Character Manager conflicts with a current website mechanic, the **website mechanic is authoritative** and the downstream artifact must be corrected.

## What this means

- A website mechanics change is the starting point for downstream synchronization.
- Books should be reviewed and updated wherever the changed mechanic is described, referenced, or affected.
- The Character Manager should be reviewed and updated wherever the changed mechanic affects character creation, progression, calculations, validation, inventory, spells, class resources, or other automated behavior.
- Lore, presentation, navigation, or other non-mechanical website changes do not automatically require changes to books or the Character Manager.
- The website does not need to reproduce every GM-only or book-only detail; this authority model applies specifically to **mechanics**.

## Versioning

**Website Rules Reference:** v1.0.0  
**Effective date:** 28 September 2026

Future mechanical changes should increment the Website Rules Reference version as appropriate. Downstream books and Character Manager releases should record the website rules-reference version they were synchronized against.

## Synchronization Principle

> **Change the website rule first. Then synchronize the books and Character Manager to that rule.**

This document establishes the workflow for Wings of Atreia and supersedes the previous book-first synchronization model.
